# Лабораторна робота №11 — NW.js

Настільна гра «Розбий блоки», створена мовою JavaScript із використанням Canvas і NW.js.

## Запуск і збирання

Встановіть Node.js, а потім виконайте команди в кореневій папці проєкту:

```sh
npm install
npm run dev
```

Щоб зібрати застосунок для Windows x64 (NW.js 0.75.1), виконайте:

```sh
npm run build
```

Готова збірка з'явиться в папці `dist/`. Команда `npm run prod` є альтернативним способом виконати те саме збирання.

## Керування та правила

- Стрілки вліво та вправо рухають платформу.
- Відбивайте м'яч і розбивайте блоки, щоб набирати очки.
- За кожні 10 очок швидкість м'яча збільшується.
- Якщо м'яч упаде, рахунок обнулиться, а блоки з'являться знову.
- За 25 очок з'явиться повідомлення «ЗНУ найкращі!!!».

## Canvas

Елемент `<canvas>` створює растрову область, у якій JavaScript малює ігрове поле, м'яч, платформу, блоки та рахунок. Контекст `2d` надає методи для малювання фігур і тексту, а анімація оновлює зображення за допомогою `requestAnimationFrame`.
